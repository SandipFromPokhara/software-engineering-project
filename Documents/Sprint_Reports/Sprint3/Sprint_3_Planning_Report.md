## Sprint Goal

The goals of Sprint 3 are to improve the backend logic, add more features, and establish a CI/CD pipeline to ensure continuous integration and delivery:

- Extend the functional prototype by completing remaining features from the product backlog.
- Integrate Jenkins for automated CI/CD pipeline.
- Enhance automated testing with comprehensive unit tests and code coverage analysis.
- Prepare for functional review by ensuring all main features are implemented and testable.
- Develop and test Docker image locally.
- Make sure application is ready for end-to-end functionality demonstration.

By the end of Sprint 3, the team aims to deliver a fully functional application with automated build and test pipelines, comprehensive test coverage, and a local Docker image ready for deployment.

## Sprint Objectives

- Extend existing CRUD functionality with advanced features
- Configure Jenkins CI/CD pipeline with automated build and test stages
- Extend unit test to cover new and existing features
- Achieve a comprehensive code coverage with JaCoCo reporting
- Create and test initial Docker image locally using Docker Desktop
- Bug fixes and performance optimization of existing features
- Update GitHub repository and Trello boards with progress
