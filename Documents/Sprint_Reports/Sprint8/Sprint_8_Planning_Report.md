## **6. Definition of Done**

A task is considered complete when:

- The task is fully implemented and meets the specified requirements.
- Localization requirements are implemented and documented.
- Code is reviewed, cleaned, refactored, and follows clean code principles.
- Relevant documentation is completed and uploaded to GitHub.
- Testing (manual, functional, integration, unit where applicable) is performed and results are documented.
- No critical bugs remain.
- All changes are committed and pushed to GitHub repository.
- Task is reviewed and approved by team members.
- Task status is updated in Trello/GitHub Projects.
