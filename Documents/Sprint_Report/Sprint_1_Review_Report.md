# Software Engineering Project 1 - Sprint Planning Report

## Sprint Number 1
Dates: 13.01.2026 - 27.01.2026

---

### Overview

Sprint 1 focused on establishing fundamental structure for the entire project i.e. NoteVault - Digital Note-taking and Annotation Application. 
The team was successfully formed and first Scrum master was selected for the first Sprint. 
Scrum master was responsible to create workspaces and setup boards in Trello. 
Then tools and frameworks were discussed, product vision and an initial Project Plan report was documented. 
A private GitHub repository was set up for version control and team collaboration. Each member will create branches and develop functionalities.
The branches will be merged to `main` by the end of the project.
Development environment was set up and necessary DevOps tools were installed.
This sprint ensured that the team had a clear direction, shared understanding and technical infrastructure required for future development.
