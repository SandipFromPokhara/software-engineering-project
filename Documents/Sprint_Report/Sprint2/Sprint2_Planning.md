## Sprint Goal
The goals of the Sprint 2 are to establish core foundation of the NoteVault application:
- Set up the database and ensure it supports basic CRUD operations.
- Begin developing the user interface based on the design prototype
- Extend Software Architecture and Data Modelling (UML diagrams and ER diagrams)
- Integrate essential development tools such as unit testing and code coverage
- Preparing the system for more advanced testing and CI/CD activities in sprint 3
- Deliver the first working version of the application with basic functionality and testing support.

- By the Sprint 2, the team aims to deliver the first working version of the application with basic CRUD operation, initial UI screens and automated testing infrastructure

---

## Sprint Objectives
-	Implement the relational database using MariaDB.
-	Begin development of the JavaFX user interface based on the Figma prototype.
-	Extend and refine the software architecture and data model.
-	Integrate JUnit for testing.
-	Configure JaCoCo for code coverage reporting.
-	Update GitHub and Trello to reflect progress and maintain workflow. Transparency.

## Definition of Done:
A task is complete when:
